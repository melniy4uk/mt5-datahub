# mt5-datahub

**mt5-datahub** — Python-библиотека для получения исторических **тиков и свечей MetaTrader 5** с локальным кэшем **Parquet + SQLite**. Повторный запрос читает сохранённые данные, а при расширении диапазона библиотека запрашивает отсутствующие участки у MT5.

Работает с **историей терминала MT5**, а не с биржевым API. **Не отправляет ордера и не торгует.** Версия: **0.2.0**.

## Возможности

- Тики и свечи в формате структурированных `numpy.ndarray`; свечи — только закрытые.
- Повторное чтение из кэша и дозагрузка недостающих интервалов.
- Порционная выдача `iter_ticks()` и прогрессивная загрузка `stream_ticks()`.
- Контролируемое обновление истории через `refresh_ticks()` / `refresh_candles()`.
- Проверка кэша, аудит тиков, сверка с MT5 и со свечами M1.
- Очистка повреждённых записей, уплотнение Parquet и ручное удаление неиспользуемых файлов.

## Установка

Нужны **Windows x64**, **Python 3.13 или 3.14**, [uv](https://docs.astral.sh/uv/), установленный терминал **MetaTrader 5** с подключённым торговым счётом и доступной историей.

```powershell
git clone https://github.com/melniy4uk/mt5-datahub.git
cd mt5-datahub
uv sync --locked
```

Пакет пока **не опубликован в PyPI**. Команды выше устанавливают проект из репозитория. Если в терминале символ называется иначе, замените `XAUUSD.s` на имя своего инструмента.

## Быстрый старт

```python
from datetime import UTC, datetime
import MetaTrader5 as mt5
from mt5_datahub import MarketData

start = datetime(2026, 10, 20, 10, 0, tzinfo=UTC)
end = datetime(2026, 10, 20, 10, 10, tzinfo=UTC)

with MarketData(
    cache_dir=".mt5-datahub",
) as data:
    ticks = data.get_ticks("XAUUSD.s", start, end)
    candles = data.get_candles("XAUUSD.s", mt5.TIMEFRAME_M1, start, end)

print(f"Тики: {len(ticks)}; закрытые M1: {len(candles)}")
print(ticks[["time_msc", "bid", "ask"]][:3])
```

**`source` теперь указывать не нужно:** по умолчанию библиотека берёт сервер и логин подключённого счёта MT5 и использует имя кэша вида `mt5:Bybit-Live-6/12345678` (номер условный). При смене счёта в рамках одного экземпляра `MarketData` возникает ошибка, предотвращающая смешивание данных. После `connect()` выбранное имя доступно через `data.source`. Для старого кэша или собственного имени передайте `source="my-history"` явно — старые записи автоматически не перемещаются. Номер счёта сохраняется **локально** в индексе кэша и может попадать в логи; пароль не сохраняется.

**Даты:** timezone-aware `datetime` (рекомендуется UTC). Интервалы **[start, end)**: начало включено, конец исключён. У свечей время относится к **открытию бара**. Тики имеют миллисекундные метки `time_msc`, свечи — секунды `time`.

### Готовый сценарий

```powershell
uv run python examples/workflow.py --symbol XAUUSD.s
```

Скрипт загружает тики и M1, повторно читает тики из кэша и выполняет локальную проверку и аудит.

## Что важно знать

Кэш хранит результаты запросов, **но не доказывает полноту брокерской истории**. Пустой ответ MT5 не считается заполненным интервалом. `get_ticks()` собирает весь результат в оперативной памяти; для больших архивов используйте `iter_ticks()` или `stream_ticks()`. На один `cache_dir` допускается **один процесс записи**.
